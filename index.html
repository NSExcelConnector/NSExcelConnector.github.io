Setup in minutes

Three steps to live data

No developers, no add-ins, no IT requests. If you can install a SuiteApp, you're done.

01

Install the SuiteApp

Admin installs the NetSuite bundle in minutes. No scripting knowledge required — it deploys the Suitelet and token manager automatically.

02

Generate a token URL

Pick any saved search in the Token Manager and generate a secure, shareable URL. Revoke it anytime with one click — no need to change passwords.

03

Paste into Excel

Users go to Data → Get Data → From Web, paste the URL, and data loads instantly. Hit Refresh All to update — no logins, no add-ins.

Each saved search gets its own cryptographically signed URL. Share it with contractors or external teams without granting NetSuite access. Revoke instantly — no password changes, no ticket required.

CSV & HTML Output

Any Saved Search

If you can save it in NetSuite, you can expose it. AR aging, inventory, transactions, custom records — all fair game.

Power BI

Use Get Data → Web in Power BI Desktop or Power BI Service. Paste the token URL and your NetSuite data becomes a live dataset — build reports, visuals, and dashboards that refresh on schedule.

Google Sheets

Use the built-in IMPORTHTML() function to pull live data directly into a cell. No add-ons, no OAuth setup — just paste the URL and a table index.

Looker Studio

Connect via the Custom URL connector or use Google Sheets as an intermediary. Your NetSuite data flows straight into Looker Studio reports and executive dashboards.

Custom Dashboards

Fetch the URL from any app, script, or dashboard using a standard fetch() or requests.get() call. HTML table output works with any HTML parser.

n8n & Zapier

Pull live NetSuite data into any automation workflow. Use an HTTP node to fetch the URL, parse the response, and trigger downstream actions — no custom API integration needed.

Klipfolio

Use Klipfolio's REST/URL data source to connect directly to your token URL. Build real-time KPI dashboards and klips that refresh automatically from live NetSuite data.
